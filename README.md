# 로또

## 프로그램 개요

로또 프로그램은 콘솔 기반의 간단한 로또 발매기 입니다. 사용자가 로또를 구매하고자 하는 금액을 입력하면 개당 1,000원으로 금액만큼 구매합니다. 모든 로또는 번호가 랜덤으로 발행되며, 사용자가 당첨 번호와 보너스 번호를 입력할 수 있습니다. 이후 당첨 결과와 수익률을 확인할 수 있습니다.

## 주요 기능

- **로또 발행**
  - 사용자가 로또를 구매하고자 하는 금액을 입력하면 개당 1,000원으로 금액만큼 구매합니다.
  - 모든 로또는 번호가 1~45 사이의 중복되지 않는 6개의 숫자로 구성됩니다.
- **당첨 번호 입력**
  - 사용자가 당첨 번호와 보너스 번호를 입력할 수 있습니다.
  - 당첨 번호는 1~45 사이의 중복되지 않는 6개의 숫자로 구성됩니다.
  - 보너스 번호는 1~45 사이의 당첨 번호와 중복되지 않는 1개의 숫자로 구성됩니다.
- **당첨 결과 확인**
  - 당첨 결과와 수익률을 확인할 수 있습니다.
  - 당첨 결과는 1등, 2등, 3등, 4등, 5등, 6등의 순서로 출력됩니다.
  - 수익률은 구매 금액에 대한 당첨 금액의 비율로 출력됩니다.
- **에러 처리**
  - 사용자가 잘못된 값을 입력할 경우 `[ERROR]`로 시작하는 메시지와 함께 Error를 발생시키고 해당 메시지를 출력한 다음 해당 지점부터 다시 입력을 받습니다.

## 당첨 기준 및 상금

| **등수** | **당첨 기준**                    | **상금(원)**  |
| -------- | -------------------------------- | ------------- |
| 1등      | 6개 번호 일치                    | 2,000,000,000 |
| 2등      | 5개 번호 일치 + 보너스 번호 일치 | 30,000,000    |
| 3등      | 5개 번호 일치                    | 1,500,000     |
| 4등      | 4개 번호 일치                    | 50,000        |
| 5등      | 3개 번호 일치                    | 5,000         |

## 구현 기능 목록

- [x] 로또 구매 금액을 입력받는다.
  - [x] 1,000원으로 나누어 떨어지지 않을 경우 에러를 발생시킨다.
- [x] 1,000원 단위로 로또를 구매한다.
- [x] 로또를 구매한 후 로또 번호를 1~45 사이의 중복되지 않는 랜덤 숫자 6개로 생성한다.
  - [x] 1~45 사이의 정수가 아닌 경우 에러를 발생시킨다.
  - [x] 중복되는 숫자가 있을 경우 에러를 발생시킨다.
- [x] 로또 번호를 출력한다.
- [x] 당첨 번호 6개를 중복되지 않는 숫자로 입력한다.
  - [x] 중복되는 숫자가 있을 경우 에러를 발생시킨다.
  - [x] 1~45 사이의 정수가 아닌 경우 에러를 발생시킨다.
  - [x] 6개가 아닌 경우 에러를 발생시킨다.
- [x] 보너스 번호 1개를 중복되지 않는 숫자로 입력한다.
  - [x] 당첨 번호와 중복되는 숫자가 있을 경우 에러를 발생시킨다.
  - [x] 1~45 사이의 정수가 아닌 경우 에러를 발생시킨다.
- [ ] 당첨 결과를 출력한다.
- [ ] 수익률을 출력한다.
