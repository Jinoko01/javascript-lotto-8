# 로또

## 프로그램 개요

로또 프로그램은 콘솔 기반의 간단한 로또 발매기 입니다. 사용자가 로또를 구매하고자 하는 금액을 입력하면 개당 1,000원으로 금액만큼 구매합니다. 모든 로또는 번호가 랜덤으로 발행되며, 사용자가 당첨 번호와 보너스 번호를 입력할 수 있습니다. 이후 당첨 결과와 수익률을 확인할 수 있습니다.

## 주요 기능

- **로또 발행**
  - 사용자가 로또를 구매하고자 하는 금액을 입력하면 개당 1,000원으로 금액만큼 구매합니다.
  - 모든 로또는 번호가 1~45 사이의 중복되지 않는 6개의 숫자로 구성됩니다.
- **당첨 번호 입력**
  - 사용자가 당첨 번호와 보너스 번호를 입력할 수 있습니다.
  - 당첨 번호는 1~45 사이의 중복되지 않는 6개의 숫자로 구성됩니다.
  - 보너스 번호는 1~45 사이의 당첨 번호와 중복되지 않는 1개의 숫자로 구성됩니다.
- **당첨 결과 확인**
  - 당첨 결과와 수익률을 확인할 수 있습니다.
  - 당첨 결과는 1등, 2등, 3등, 4등, 5등, 6등의 순서로 출력됩니다.
  - 수익률은 구매 금액에 대한 당첨 금액의 비율로 출력됩니다.
- **에러 처리**
  - 사용자가 잘못된 값을 입력할 경우 `[ERROR]`로 시작하는 메시지와 함께 Error를 발생시키고 해당 메시지를 출력한 다음 해당 지점부터 다시 입력을 받습니다.

## 당첨 기준 및 상금

| **등수** | **당첨 기준**                    | **상금(원)**  |
| -------- | -------------------------------- | ------------- |
| 1등      | 6개 번호 일치                    | 2,000,000,000 |
| 2등      | 5개 번호 일치 + 보너스 번호 일치 | 30,000,000    |
| 3등      | 5개 번호 일치                    | 1,500,000     |
| 4등      | 4개 번호 일치                    | 50,000        |
| 5등      | 3개 번호 일치                    | 5,000         |

## 사용 방법

1. **프로그램 실행**: 터미널에 `npm run start`를 입력해 프로그램을 실행합니다.

```bash
npm run start
```

2. **로또 구매 금앱 입력**: 로또를 구매할 금액을 입력합니다. 로또는 1장당 1,000원으로 구매됩니다.

- 예시

```bash
구매 금액을 입력해주세요.
5000
[1, 8, 11, 25, 31, 42]
[2, 4, 13, 26, 29, 35]
[7, 9, 11, 17, 20, 25]
[4, 5, 10, 15, 22, 45]
[1, 6, 20, 24, 38, 43]
```

3. **당첨 번호 입력**: 당첨 번호를 콤마(,)로 구분하여 입력합니다. 당첨 번호는 1~45 사이의 중복되지 않는 6개의 숫자로 구성됩니다.

- 예시

```bash
당첨 번호를 입력해주세요.
1,2,3,4,5,6
```

4. **보너스 번호 입력**: 보너스 번호 하나를 입력합니다. 보너스 번호는 1~45 사이의 당첨 번호와 중복되지 않는 숫자로 입력합니다.

```bash
보너스 번호를 입력해주세요.
7
```

[13, 14, 16, 38, 42, 45]

당첨 번호를 입력해 주세요.
1,2,3,4,5,6

7

---
3개 일치 (5,000원) - 1개

## 에러 처리 예시

```bash
[ERROR] 구매금액은 1,000원 단위의 정수로 입력해야 합니다.
(예시: 5000)
```

- **ApplicationTest.js**

  - 전체 플로우 E2E 시나리오 검증(구입→발행→입력→통계/수익률 출력)

  - 잘못된 입력 시 에러 발생 검증

- **InputViewTest.js**

  - 구매 금액 입력: 1000원 단위의 정수 허용, 대용량 숫자 허용
  - 구매 금액 예외: 1000원 단위 아님, 소수/비숫자/형식 오류 → 에러
  - 당첨 번호 입력 예외: 개수(6개 아님), 범위(1~45 벗어남), 중복, 비숫자/형식 오류 등 → 에러
  - 보너스 번호 입력 예외: 당첨 번호와 중복, 범위/형식 오류 → 에러

- **LottoFactoryTest.js**

  - 지정한 개수만큼 로또 객체 리스트 생성 검증

- **LottoTest.js**

  - 번호 개수 6개 초과/미만 → 에러
  - 중복 번호 존재 → 에러
  - 번호 범위(1~45) 위반 → 에러

  - `determineRank`가 입력된 매치 결과들을 랭크별 집계로 변환하는지 검증
  - 6개, 5개+보너스, 5개, 4개, 3개 각 1회씩 집계 확인

- **ProfitCalculatorTest.js**

  - 랭크별 집계와 구매 금액으로 수익률 계산(예: 8000원, 3개 일치 1개 → 62.5%)

- **OutputViewTest.js**
  - 구매한 로또 리스트 출력 포맷 검증
  - 당첨 결과 라인(3개~6개) 포맷 및 금액 콤마 표기 검증
  - 수익률 출력 문구 포맷 `총 수익률은 X%입니다.` 검증
